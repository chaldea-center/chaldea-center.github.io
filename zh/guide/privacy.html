隐私政策 ​

版本：v1 · 生效日期：2026 年 10 月 25 日

本政策说明 Chaldea 服务提供者知行远景（台州）科技有限公司（以下称“我们”）在提供 Chaldea App 及相关服务时如何处理个人信息，以及你可以如何管理这些信息。

隐私问题与权利请求请通过联系我们页面提出。我们将在收到隐私投诉或权利请求后 15 个工作日内答复。

一、基本功能与可选服务 ​

Chaldea 提供游戏资料查询、素材规划、队伍与战斗模拟等工具。基础本地功能不要求你注册账号或提供姓名、手机号、身份证。联网获取游戏资料、图片和更新时，请求的服务器会接收 IP 地址及必要的网络请求信息。

账号、云端恢复、在线队伍发布、GitHub 备份、产品分析、故障诊断及广告属于具体场景下的服务。拒绝非必要个人信息处理不应阻止你使用无关的基础功能。系统权限、个性化广告偏好和隐私同意是不同的选择，不能相互替代。

二、我们处理哪些信息 ​

使用场景信息范围用途及触发方式
本地规划、模拟及数据管理你录入的游戏进度、规划、队伍、偏好设置在设备中保存与计算；你主动备份、分享或反馈时，相关内容可能离开设备
注册、登录与账号维护用户名、邮箱、密码验证信息、会话及设备标识；请求 IP、App 版本、平台和语言提供账号、邮箱验证、修改信息、密码重置、辅助找回与安全管理。服务端保存密码哈希用于验证
云端恢复副本账号关联信息、你主动上传的用户数据文件、上传时间临时恢复或在设备间迁移；它不是永久保管服务，请保留自己的本地备份
在线队伍你提交的队伍、说明、署名/账号关联、投票与操作记录发布、浏览、维护及管理队伍。发布的内容可被其他人查看，请勿包含无关个人信息
本地备份、文件导入导出你选择的备份、JSON/CSV 文件及导出内容由你操作系统文件选择器或分享功能；选择文件不表示授权读取设备上所有文件
剪贴板导入你主动粘贴或导入的文本、数据或队伍链接解析本次导入内容；不以此持续采集剪贴板
保存、复制或分享图片你选择的图片、生成的规划/队伍图片写入相册、剪贴板或发送至你选择的应用；接收应用适用其自身政策
更新与 APK/XAPK 下载、安装版本、平台/渠道、下载请求及安装包检查或获取更新、下载游戏安装包；可用方式和安装授权依平台与渠道而异
主动反馈反馈正文、你提供的联系方式、诊断日志、设备/App 参数及随反馈发送的数据文件或附件你主动提交后用于回复与排障。请检查反馈内容，避免发送密码、Token 或不相关个人信息
自动故障诊断（可选）技术日志、错误堆栈、设备及 App 参数经你允许后用于排障；自动报告不包含截图、完整用户文件或设置快照
产品分析（可选，Android/iOS）SDK 设备标识、设备/系统和 App 参数、IP、会话、页面及操作事件、语言、游戏区服偏好和渠道通过我们的 Countly 服务了解功能使用与稳定性。设备标识可关联记录，不将这些数据称为完全匿名
广告（仅启用广告的版本/渠道）见第三方 SDK 清单中的设备、网络、标识符与广告互动信息广告展示、统计、归因及反作弊；个性化广告另受你的偏好和系统授权控制

自动诊断与主动反馈的范围不同。 主动提交反馈不会因关闭自动诊断而被阻止。自动诊断仅在你同意并开启该选项时进行。

三、系统权限与设备能力 ​

我们按功能需要使用设备能力。你可以在系统的 Chaldea 应用设置中查看或调整可管理的授权；不同系统、版本和渠道显示的项目可能不同。拒绝某项权限会影响相应操作，不应影响无关的本地功能。

权限/能力平台与使用说明
网络、网络状态及 Wi-Fi 状态用于请求资料、图片、账号、更新及已启用的服务。Android 的普通网络权限通常不弹出运行时授权框
照片添加/保存图片iOS 保存你选定的图片，需要时申请仅添加照片的授权；保存图片不要求读取整个照片库
旧系统存储读写Android 包含 READ_EXTERNAL_STORAGE（最高 SDK 32）及 WRITE_EXTERNAL_STORAGE（最高 SDK 28）声明；旧系统保存图片/文件兼容路径可能需要授权。系统文件选择器仅授予你选定内容的访问
安装未知应用Android GitHub/F-Droid 渠道在你主动安装 APK/XAPK 时可能需要前往系统开启。Google Play 渠道包不含 REQUEST_INSTALL_PACKAGES
电话状态Android 包仍保留 READ_PHONE_STATE；广告 SDK 可能在系统允许范围内使用电话状态相关信息进行设备识别与反作弊。它不是基础本地功能的必要条件，不授权读取通话内容
广告标识与跟踪Android 广告 ID 的可用性取决于系统和设置；iOS 的 IDFA 跟踪授权由系统 ATT 决定。拒绝或撤回跟踪授权后，不应使用其他标识绕过你的选择

安装包声明、实际请求与系统授权并不相同。SDK 的内部签名权限用于组件通信，不是需要你在界面上开启的个人信息权限。我们不将未开放功能的残留声明作为收集信息的理由。

四、第三方 SDK 与你选择的外部服务 ​

我们使用 SDK 提供广告、可选产品分析及网页展示等能力。组件名称、提供方、版本、处理信息及适用范围详见第三方 SDK 清单。该清单是本政策的组成部分，适用相同版本和生效日期。

你主动配置 GitHub Token、仓库及路径进行备份/恢复时，相关凭据与备份内容用于请求 GitHub。请使用最小范围 Token，确认仓库可见性；公开仓库可能公开备份内容。GitHub 的独立处理及存储适用 GitHub 隐私声明。

你打开资料、视频、文档、社群或捐赠等外链时，第三方会接收相应访问请求；其政策适用于其独立服务。系统分享由你选择的接收应用处理。

五、广告与可选处理的管理 ​

你可在“设置 → 隐私与数据”管理个性化广告、自动崩溃诊断和产品分析偏好，在广告设置管理可用的广告选项。个性化广告偏好初始为开启；该偏好不等于授予系统权限，也不代替依法需要的同意。关闭个性化广告后，已启用广告的服务应提供非个性化方式；并不因此消除广告投放所必需的网络请求。

iOS 跟踪授权还须遵守 ATT 选择。撤回同意不影响撤回前依法进行的处理；删除已留存信息可按第八节联系我们。关闭相应的可选处理后，我们将停止该项处理；撤回同意不影响你主动提交反馈。

六、保存地点与期限 ​

我们的自有账号与云端恢复服务部署在中国境内。你主动使用的 GitHub、第三方网页或其他独立服务可能涉及其境外基础设施；请结合对应服务政策决定是否使用。上述境内存储说明不适用于你主动使用的独立第三方服务。

自本政策生效之日起，我们按以下规则保存个人信息。期限届满后应删除或进行不能复原、不能再识别个人的匿名化；法律另有保存要求的，仅为履行该要求保留。

数据保存期限或删除条件
设备本地数据与本地导出文件由你保存、覆盖或删除；卸载是否清除还取决于系统备份、外部目录及你保存的副本
账号与服务记录提供账号服务所需期间；注销或达到删除条件后依法删除/匿名化。必要的安全及法定留存另行处理
云端恢复副本自上传起最长 7 天，被替换、主动删除或注销时可能提前删除
自动故障诊断报告自收到报告起 90 天
主动反馈及所附材料自收到反馈起 180 天
Countly 中可关联个人或设备的分析记录自记录起 90 天
你公开发布的队伍在你保留发布或为处理必要的服务争议期间；你可删除自己的发布，第三方已保存的公开副本不由我们控制
依法要求的相关网络安全日志适用法律要求的期限；适用《网络安全法》相关网络日志要求时不少于 六个月。不将此要求扩展为所有诊断/分析数据的统一保存期限
灾备副本、反馈接收邮箱/转发副本及网站工具我们管理的灾备、反馈收件箱和转发副本适用对应数据的保存期限；网站统计服务商的保存规则见第九节所链接的隐私政策

GitHub 中的副本由你及 GitHub 的设置管理；第三方 SDK 独立保存的数据按其政策及适用法律处理，我们将协助你提出相关请求。

七、共享、安全与变更用途 ​

我们为提供你选择的服务使用必要的技术、托管和通信服务，不因你使用基础功能便授权任意共享。委托处理、向独立第三方提供、公开发布及你主动分享具有不同含义；我们会按具体关系与适用法律履行告知、约束和必要的同意程序。

反馈内容及附件用于回复和排障，可能通过为我们提供邮件、通信或托管服务的供应商处理。涉及依法需要另行告知的接收方或境外提供情形时，我们会在处理前履行告知及必要的同意或其他法定程序。新增目的、接收方或处理方式需依法重新告知、取得必要同意时，我们会先履行相应程序。

我们采取与服务相适应的访问控制、传输保护和账号安全措施。请妥善保管密码、Token、备份与分享内容；发生个人信息安全事件时，我们将依法采取处置及通知措施。

八、你的权利与联系方法 ​

Chaldea 及相关服务由知行远景（台州）科技有限公司提供。你可以在 App 中修改可用的账号信息、删除自己的在线内容、管理可选处理和系统权限，并通过账号注销入口申请注销。注销云端账号不等于自动删除你已导出的文件、GitHub 副本或接收方保存的分享内容。

如需查阅、复制、更正、补充、删除个人信息、撤回同意、注销账号或对处理提出异议，请通过联系我们页面提出请求。我们只会为核实请求收集必要信息，不要求你发送完整密码或 Token。我们将在 15 个工作日内答复；无法直接办理的，将说明原因与可行途径。你也可依法向有权机关投诉。

九、文档网站 ​

文档网站使用 Google Analytics 和百度统计了解访问情况，可能处理 Cookie、IP 地址、设备/浏览器信息和页面访问记录。相关处理方式见 Google 隐私政策和百度统计隐私政策。网站统计与 App 内的 Countly 属于不同的处理场景。

十、政策更新 ​

本政策的版本与生效日期见页首。如发生重要变更，将以政策页及必要的 App 提示告知；依法需重新取得同意的，不以继续使用自动替代同意。
